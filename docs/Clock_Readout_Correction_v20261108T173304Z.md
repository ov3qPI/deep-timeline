# Centerline clock correction 20261108T173304Z
The original rotated text was drawn around local `(0,0)` after a rotation about the viewport centerline, placing the label outside the screen. The correction computes a glyph-centered baseline at the Canvas rotation pivot, located to the left of the timeline axis at exactly half the timeline viewport height. It scales down only when the label would exceed the available timeline height. It updates on scrolling and GPS/manual observer-longitude changes. When no longitude is configured, it displays the center instant in UTC and explicitly prompts to set longitude.
