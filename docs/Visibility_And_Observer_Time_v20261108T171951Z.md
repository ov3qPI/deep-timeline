# Deep Timeline — Observer longitude and scale-dependent events
The left gutter displays the local mean solar time at the vertical viewport midpoint, written vertically bottom-to-top. Configure the observer longitude by touching the left gutter or long-pressing the Now toolbar icon. Enter either a longitude alone or latitude, longitude, or request GPS. The setting persists in private preferences and does not alter the timeline center instant or stored events. Without a configured longitude, the gutter prompts for one rather than inferring a location. Longitudinal time is UTC plus longitude × 240 seconds, including fractional nanoseconds; dates use BCE without year zero.
Each event may have an optional maximum visible span. In Edit Event, enter a positive amount and select days (86,400 s), mean synodic months (29.530588853 d), or mean solstice years (365.24274 d). When the entire visible time span exceeds this threshold, the event has no tick, connector, label, or effect on hyperflow. At or below the limit the event is visible. Empty means always visible. The Event Data toolbar menu includes a bulk editor using the existing selection checklist. The visibility value/unit survive JSON import and export through an optional maxVisibleSpan object, and a database version 3 migration. Previous JSON exports omit the property and therefore import as always visible.
This is an event visibility filter only, not deletion. Zooming back in restores hidden events. The diagnostic screen shows the observer and visible-event count. JSON backups include visibility limits. The full native APK build must be run in Termux; JVM tests cover the chronology and visibility rules.
