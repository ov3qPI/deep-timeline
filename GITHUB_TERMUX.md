# Deep Timeline repository and Termux workflow
This public repository contains Kotlin source, Android resources, build scripts, and project documentation. It does not contain compiled APKs, signing keys, passwords, personal timeline JSON exports, or generated build products.
The current Android application ID is `org.deeptimeline.app`. Its signing certificate and event database must remain compatible across updates.
Build from the repository source using `bash deep_timeline_secure_build_v20261109T020314Z.sh`. The wrapper prompts privately for the original signing password; `build.sh` checks the original certificate fingerprint, alias, and signing credentials before compilation or dependency downloads. The original keystore is persisted at `/storage/emulated/0/Documents/keystore/deep_timeline_signing.keystore`. A matching legacy keystore at `$HOME/.deep_timeline_signing.keystore` is moved to that location after successful preflight.
Keep signing material out of Git. Shared Android storage is not private from every app, so keep an additional protected copy of the original signing material outside the disposable Termux home. Do not uninstall an existing Deep Timeline installation to resolve a build or signing error.
`deep_timeline_source_publish_v20261109T022523Z.sh` is an initial-repository publisher, not a command to update this existing repository. Subsequent source changes should be committed through the normal Git workflow.
